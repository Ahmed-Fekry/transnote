# TransNote — Transparent Notepad

A beautiful transparent notepad that floats above all your windows.

## Setup

```bash
npm install
npm start
```

## Features
- Adjustable transparency (15% to 100%)
- Always stays on top of other windows (toggle with 📌)
- Auto-saves as you type
- 4 color themes: Green, Warm, Cool, Rose
- Toggle between serif and monospace font
- Word & character count
- Frameless glass design
